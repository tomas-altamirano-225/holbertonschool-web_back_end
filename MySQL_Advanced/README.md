# MySQL Advanced

## Descripción
Este proyecto explora conceptos avanzados de bases de datos relacionales utilizando MySQL. El objetivo principal es trasladar la lógica de negocio y la validación de datos directamente a la base de datos para garantizar la integridad, optimizar el rendimiento y reducir la carga en el servidor de la aplicación.

## Conceptos Aplicados
* **Integridad de Datos:** Uso de restricciones (`NOT NULL`, `UNIQUE`, `ENUM`).
* **Optimización:** Creación de Índices (B-Tree) para acelerar consultas en tablas con millones de registros.
* **Automatización:** Implementación de Triggers para ejecutar acciones automáticas tras eventos de inserción o actualización.
* **Procedimientos y Funciones:** Uso de `Stored Procedures` y `Functions` para calcular y almacenar métricas complejas (ej. promedios ponderados) directamente en el motor de SQL.
* **Vistas:** Creación de `Views` para abstraer consultas complejas.
