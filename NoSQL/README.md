# NoSQL

## Description
This project introduces the concepts of NoSQL databases, specifically using MongoDB. It covers the basics of interacting with a document-oriented database, both through the Mongo shell and using Python with the `pymongo` library.

## Topics Covered
* What NoSQL means and the difference between relational (SQL) and non-relational (NoSQL) databases.
* How to use MongoDB: creating collections, inserting documents, querying, updating, and deleting.
* Interacting with MongoDB programmatically using Python (`pymongo`).
* Log parsing and aggregation operations using MongoDB.

## Repository Contents
* `0-list_databases` to `7-delete`: Basic MongoDB shell scripts for CRUD operations.
* `8-all.py` to `12-log_stats.py`: Python scripts using `pymongo` to interact with MongoDB collections and perform data analysis.
